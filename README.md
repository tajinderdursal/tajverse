
# TajVerse 🌐

TajVerse is a modern, interactive personal web experience built to showcase projects, skills, creativity, and experimentation with 3D web technologies.

## 🚀 Tech Stack

* Next.js
* React
* JavaScript
* Tailwind CSS
* Three.js
* React Three Fiber
* React Three Drei

## ✨ Features

* Interactive and responsive UI
* 3D web elements and animations
* Smooth scrolling and transitions
* Project showcase
* Skills and technology section
* Modern responsive design
* Optimized for desktop and mobile

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/tajverse.git
```

Navigate to the project:

```bash
cd tajverse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
